## 2. 運用（2026-08-22 に変更）

### 変更の理由

教科書（BibliU）は**コピーできない**。以前の「教科書の英文を対訳にして本棚に読み込む」運用は、
ユーザーが英文を渡せることを前提にしていたため成立しない。
加えて**本棚は端末内のみで同期されない**ため、iPhoneでの復習にも使えなかった。

### いまの運用

```
読む → 詰まる → 写真か入力でClaudeに渡す → 解説 → アプリに貯める
```

| 中身 | 入れる場所 | 同期 |
|---|---|---|
| 語彙（訳・解説・例文） | `index.html` の `SEED_WORDS` | ○ |
| 構文・語法・論点の解説 | `index.html` の `SECTIONS` | ○ |
| 確認テスト | `index.html` の `QUIZ` | ○ |

**すべて `index.html` に入る。** push すれば全端末で読める。ユーザー側の貼り付け作業は不要
（単語だけ、アプリの「最新の収録単語を取り込む」を1回押す）。

### 書くときの約束

- **教科書の文をそのまま入れない。** 訳・解説・例文はこちらで書き下ろす
- 例文は短く、その語の使い方が分かるものにする
- `SECTIONS` の `n` は、語彙・構文まわりなら `英1` `英2` … と付ける（章の要点と混ざらないように）
- 読み手は管理部門ひとすじ30年の経理責任者。**会計の中身は既知で、英語だけが壁**
- 日本基準と違う論点は1行だけ注記する。長い解説は書かない

### push 前に必ず

```bash
node runcheck.js index.html
node mergetest.js
```

構文チェックだけでは、**変数の宣言順ミスでアプリ全体が無反応になる不具合**を検出できなかった実績がある。

### 単語のたまり方

覚えたい語はその都度 push せず、`SEED_WORDS` 末尾に追記して未コミットで溜める。
まとまった時点でユーザーの合図で一括コミット＆push。

### 本棚（マイ対訳）の扱い

**主役から外した。** 機能は残してあるが、新しく対訳JSONを作らない。
`translations/` は gitignore 済みで、既存の `第1章_語句と構文.json` は
このPCの読み上げ練習用として残置。

## 4. 記事の種（気づいたら1行だけ）

読んでいて「日本の実務とここが違う」と思ったことを置く場所。
note連載の材料になるが、**ここでは記事を書かない**（連載の正本は `C:\Dev\acca-note`）。

- 会計英語の account は「勘定」ではなく「説明」が原義。accountability も accountant も同語源で、会計の本質が計算ではなく説明にあることを示している（2026-08-22）
- 財務諸表の利用者として列挙される人々と、基準が想定する primary users は一致しない。従業員や政府が外れる理由が「必要としないから」ではなく「別の入手手段があるから」なのが面白い（2026-08-22）

## 5. 決まっていること

- **読むことと覚えることを分ける**（2026-08-22決定・**「解説は答え合わせ」は撤回**）
  - 読むとき＝**理解を優先して速度を落とさない。** わからない語と文はすぐ渡す。解説は出し惜しみしない
  - 覚えるとき＝アプリで回す。**単語力と文章力はここでつける**
  - **問題集は自力で解く。解く前に訳さない・解説しない。** 出番は解いたあと、間違いと不明だけ
  - 理由と却下案：保管庫の `判断ログ\20260822_ACCA学習法_読むと覚えるを分ける.md`
- 教科書本文は**リポジトリにコミットしない**（`translations/` はgitignore済）
- アプリに最初から入る `SECTIONS` / `SEED_WORDS` / `QUIZ` は**こちらの書き下ろし**。原文を貼らない
- 学習の全体計画は保管庫の `判断ログ\20260817_ACCA学習スケジュールとnote連載の両立.md` が正本
