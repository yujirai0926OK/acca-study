## 2. 渡し方・受け取り方

### こちら（Claude）が出すもの

`translations/` に JSON を1ファイル。ファイル名は `第N章_節.json` など分かる名前で。

```json
{
  "type": "acca-bookshelf",
  "passages": [
    { "id": "c01-s01", "title": "第1章-1 財務報告とは", "en": "...", "ja": "..." }
  ]
}
```

### ユーザー側の取り込み

1. アプリを開く（https://yujirai0926ok.github.io/acca-study/ ）
2. 「📕 本棚だけを移す」→ **⬆️ 本棚を読み込み（追加）**
3. JSONを選ぶ

**同じ `id`／`title` は上書き、違えば追加。** 進捗・単語・自作テストには影響しない。

### 注意

本棚は**同期されない**（教科書本文を端末外に出さない設計）。
PCとiPhoneの両方で読みたいときは、**両方の端末で同じJSONを読み込む。**
